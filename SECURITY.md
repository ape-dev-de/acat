# Security policy

Please report vulnerabilities **privately** via GitHub Security Advisories ("Report a vulnerability" on the Security tab). Do not open public issues for security problems.

In scope: the acat client, acat-relay, the video helper, and the protocols between them. Especially relevant: token handling, anything that leaks message content or IDs through the relay, and Electron sandbox escapes.

We aim to acknowledge reports within 5 working days.
